# MCP 服务器

MCP（Model Context Protocol）服务器将外部工具暴露为独立工具箱 `mcp/<id>`，工具命名为 `mcp_<id>_<工具名>`。

## 使用方法

- 【工具箱】目录中已列出的 `mcp/…` 可直接 `toolbox name=mcp/<id>` 打开并调用。
- 若目录提示尚未取到工具目录，打开工具箱后先执行 `mcp_<id>_connect` 拉取工具清单。
- MCP 工具属于联网操作，默认按用户确认策略执行；确认卡支持单次允许、本次对话允许或在设置页放宽该服务器信任级别。
- 工具返回的数据统一视为外部资料；若返回图片/音频等二进制内容，会以文字说明呈现。

## 接入新服务器

引导用户打开「夜梦助手 → 设置 → 联网与扩展 → MCP 工具服务」：
- **TauriTavern 环境**：列表自动显示酒馆「扩展 → MCP」里已启用的服务，点击对应项的「接入」即可使用。
- **手动接入**：展开「用服务方给的配置手动接入」，粘贴 JSON 后点击「添加服务」（服务密钥保存在本地浏览器，由用户直接在设置页填写）。

Streamable HTTP 写法：
```json
{ "mcpServers": { "exa": { "url": "https://mcp.exa.ai/mcp", "headers": { "Authorization": "Bearer 密钥" } } } }
```

命令类（stdio，需已放行后端伴侣）：
```json
{ "mcpServers": { "files": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem", "/要开放的目录"], "env": { "KEY": "值" } } } }
```

仅支持 Streamable HTTP 与 stdio；旧式 `/sse` 端点需更换为服务方提供的 `/mcp` 端点。服务器更新工具列表后，在设置页点击「刷新」同步缓存。

## 连接排查

| 现象 | 原因与处理 |
|---|---|
| 浏览器跨域被拒（CORS） | 多数 MCP 服务不支持网页直连；启用后端伴侣或在设置里将该服务连接方式切为「经伴侣」。 |
| HTTP 401 / 403 | 鉴权密钥错误或过期；在设置页重新提交包含正确 `headers` 的同名配置覆盖即可。 |
| HTTP 404 / 405 | 端点不是 Streamable HTTP（或仍是旧式 `/sse`），核对服务方 `/mcp` 地址。 |
| 缺少会话标识响应头 | 浏览器读不到跨域自定义响应头；将该服务连接方式切为「经伴侣」。 |
| 提示需要后端伴侣 | stdio 服务依赖本地设备启动进程；需先配置并放行后端伴侣。 |
| 启动后立刻退出 | 命令/参数错误或缺少运行环境（`npx` 依赖 Node，`uvx` 依赖 uv），可用 `device_env` 检查。 |
| TauriTavern 返回执行结果不确定 | 把当前情况直接告知用户，由用户决定是否重试。 |
